## Phase 1 — Paint pipeline (no XR) — implemented

1. `IPaintable` — `void ApplyPaint(Vector2 uv, Color color, float radius, float amount);`
2. `ShaderIDs` — cached `Shader.PropertyToID` for `_PaintTex`, `_Center`, `_Radius`, `_Softness`, `_Color`, `_Amount`.
3. `PaintableSurface : MonoBehaviour, IPaintable`
   - Two 512² ARGB32 RenderTextures (ping-pong), cleared to transparent on Awake.
   - `ApplyPaint` → set stamp params → `Graphics.Blit(src, dst, stampMat)` → swap.
   - `ResetPaint()` public, not on the interface.
   - Binds paint RT through `MaterialPropertyBlock` (no shared-material bleed).
   - Releases RTs in `OnDestroy`.
4. `PaintStamp.shader` — fullscreen blit; `falloff = 1 - smoothstep(r*(1-soft), r, dist)`; alpha-over blend of `_Color` at `_Amount * falloff` onto existing paint → gradual build-up.
5. `PaintedSurface.shader` — URP lit; `_BaseMap`, `_BaseColor`, `_PaintTex`; `albedo = lerp(base, paint.rgb, paint.a)`; `_Smoothness`, `_Metallic`.
6. `DebugMousePainter` — mouse raycast → `IPaintable`, hold LMB to paint, R to reset. Editor test only.

Validate: soft stamp at the clicked UV on panel and cube; overlapping passes darken gradually; reset clears.

## Phase 2 — Spray behaviour

7. `SprayBrushData` — serializable struct: color, radius, softness, amount.
8. `SprayPainter`
   - Inputs: nozzle `Transform`, `bool IsSpraying` (set by caller).
   - Stamp at fixed interval (default 1/30 s), not per frame.
   - `Physics.Raycast` from nozzle, max distance ~1.5 m; `hit.collider.TryGetComponent(out IPaintable p)`; `p.ApplyPaint(hit.textureCoord, ...)`.
   - Note: `textureCoord` requires **MeshCollider** — setup script enforces this.
   - Optional: radius scales with hit distance (spray cone feel).

## Phase 3 — XR

9. Run setup items 1–2, then the manual XR steps above.
10. XR Origin from XRI Starter Assets into `PaintTest`.
11. `SprayGun` next to `XRGrabInteractable`: `activated` → spraying on, `deactivated` → off; feeds `SprayPainter`. Optional particle system plays while spraying.
12. Reset: controller secondary button → `ResetPaint()` on surfaces.

## Phase 4 — Device

13. Build to Quest 2 and Quest 3; profile stamp rate and RT size; walk acceptance criteria.

## Acceptance criteria

- Gun can be grabbed; trigger starts/stops spray.
- Paint only on paintable hit surface, at correct UV.
- Overlapping passes build up gradually; paint persists after release.
- Surface reset works.
- Works on flat panel and cube.
- Runs on Quest 2 and Quest 3.
